# Progress Log
# This file tracks learnings and progress across Ralph iterations

## US-001: Streamline Goal Cards (Completed)
**Date**: 2026-01-23

### Changes Made
1. **Progress bar background visibility in dark mode**: Changed `.goal-progress-bar` background from `var(--surface-sunken)` (#080808 in dark mode - too dark) to `var(--border)` (#333333 in dark mode - visible contrast).

2. **Hover state consistency**: Updated multiple hover states to use consistent accent colors:
   - `.stats-btn:hover`, `.focus-btn:hover`: Now use `var(--accent)` color with `var(--accent-subtle)` background
   - `.goal-control-btn:hover`: Same consistent accent styling
   - `.drag-handle:hover`: Same consistent accent styling
   - `.timer-pomodoro-btn:hover`: Uses `var(--danger-subtle)` background with `var(--danger)` color for tomato icon
   - Removed dark mode specific override for stats-btn hover that was inconsistent

3. **Progress bar color consistency**:
   - Active timer progress fill now uses `var(--type-timer)` and `var(--info)` instead of hardcoded colors
   - Avoidance completed progress fill now uses `var(--type-avoidance)` consistently
   - Avoidance goal styling (border, indicator) now uses `--type-avoidance` variables instead of `--warning`

### Key Learnings
- `--surface-sunken` is too dark (#080808) for backgrounds in dark mode
- All hover states should use semantic color variables (`--accent-subtle`, `--danger-subtle`) for consistency
- Type-specific colors should always use `--type-*` variables for consistent theming across color themes

## US-002: Enhance Dark Mode Visibility (Completed)
**Date**: 2026-01-23

### Changes Made
1. **Heatmap visibility in dark mode** (popup.css):
   - `--heatmap-level-0`: Changed from `#1A1A1A` to `#2A2A2A` for better contrast
   - `--heatmap-level-1`: Changed from `#064E3B` to `#0A5D47` for better visibility

2. **Progress bar missed state visibility** (popup.css):
   - `.progress-bar.bar-missed` dark mode: Changed from `var(--bg-tertiary)` (#1A1A1A) to `#3A3A3A`
   - `.legend-color.missed` dark mode: Same change for consistency

3. **Focus mode progress bar** (popup.css):
   - `.focus-progress-bar` dark mode: Changed from `var(--background-card)` to `#2A2A2A`

4. **Accent and subtle color opacity increases** (popup.css):
   - `--accent-subtle`: Increased from 15% to 25% opacity
   - `--danger-subtle`, `--warning-subtle`, `--info-subtle`: Increased from 15% to 20% opacity
   - All `--type-*-subtle` variables: Increased from 15% to 20% opacity

5. **Theme-specific dark mode updates** (theme-config.js):
   - All 5 themes (default, ocean, forest, sunset, lavender) updated with:
     - Increased `accentSubtle` opacity from 15% to 25%
     - Increased all `*Subtle` color opacities to 25%
     - Lightened `heatmap1` and `heatmap2` colors for better visibility

### Key Learnings
- 15% opacity on dark backgrounds makes elements nearly invisible
- 25% opacity provides good balance between subtlety and visibility
- Heatmap level-0 and level-1 need to be distinctly lighter than the background
- Progress path backgrounds should be at least `#2A2A2A` in dark mode for visibility
- "Missed" progress bars need explicit lighter colors (#3A3A3A) rather than relying on too-dark variables
